# CS5481 submission checklist

The report has four main-content pages covering introduction, methodology, experiments and discussion. References follow. The dedicated contribution page appears immediately before the appended presentation slides. The PowerPoint contains ten slides and notes for a 15-minute presentation.

- Open `PaperScope_Report.pdf` and fill in actual individual contributions and percentages on page 6.
- Collect every group member's signature on that same page. Save the signed copy privately for Canvas.
- Open the saved PDF and verify the percentages, signatures, page order and slides.
- Submit the signed report and Python project source through Canvas by November 24, 2026 at 23:59. See the course's Canvas instructions for fields and file packaging.
- Rehearse the live demo with the commands and examples in the repository README.

To edit the report text, update `build_report.py`. Save or export the edited PowerPoint to PDF and run `python submission/build_report.py --slides /path/to/slides.pdf` in an environment with `reportlab` and `pypdf`. Rebuild before adding signatures.
